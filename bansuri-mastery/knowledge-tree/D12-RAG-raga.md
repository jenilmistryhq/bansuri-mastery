# D12 - RAG: Raga

[Back to Knowledge Tree](../01-KNOWLEDGE-TREE.md) | Symbols: [Conventions](../05-CONVENTIONS-AND-NOTATION-KEY.md) | Raga cards: [ragas/](../ragas/README.md)

**Order (Recommendation), designed for a 6-hole C bansuri:**
Bhupali (no Ma, no Ni, no half-holes) -> Yaman (tivra Ma is all-open, easy) -> Durga (shuddha Ma
half-hole) -> Khamaj / Des (komal Ni) -> Kafi / Bhimpalasi / Bageshri (komal Ga) -> Shivranjani /
Pahadi (film and folk links) -> Bhairav / Bhairavi / Malkauns (heavy half-holing).

```
RAG Raga
+-- Listening ............... RAG-01 structured listening
+-- First ragas ............. RAG-02 Bhupali, RAG-03 Yaman, RAG-04 Durga
+-- Expanding ............... RAG-05 Khamaj/Des, RAG-06 Kafi/Bhimpalasi/Bageshri, RAG-08 Shivranjani/Pahadi, RAG-07 Bhairav/Bhairavi/Malkauns
+-- Performance skills ...... RAG-09 swar vistar/alap, RAG-10 bandish/gat, RAG-11 taans, RAG-12 full presentation
+-- Depth ................... RAG-13 similar-raga distinctions, RAG-14 time and rasa theory
```
