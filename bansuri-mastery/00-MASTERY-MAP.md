# Mastery Map

The whole course on one page: phases, lessons, milestones and the order between them.

## Overview

```
 PHASE 0        PHASE 1           PHASE 2              PHASE 3                 PHASE 4                 PHASE 5
 Setup          Foundations       Core technique       Musicianship            Intermediate artistry   Advanced and
 Day 0          ~Weeks 1-6        ~Weeks 7-18          ~Weeks 19-44            ~Months 10-20           independence
                                                                                                       Month 20+
 [M0]           [M1] [M2]         [M3] [M4]            [M5] [M6] [M7]          [M8] [M9]               [M10]
 flute, tools   tone, S R G,      tivra M, madhya      ragas Bhupali/Yaman,    komal notes, new ragas, full raga
 habits         .N .D .P, pulse,  P D N, tala, shuddha taar saptak, meend,     transposition, alap,    presentation,
                sargam, first     m, intonation,       kan, murki, songs by    bandish+taans+tihai,    heavy-komal ragas,
                melodies          song-learning        ear, Bhatkhande,        gamak, accompaniment,   collaboration,
                                  method, ear L2-L4    improv, composition     style, performance      own plans
```

**All timings are typical estimates at 45-60 minutes a day.** You move on when you pass a
milestone, not when the calendar says so. Some learners are faster in some areas and slower
in others. That is expected.

## Phases

| Phase | Typical duration | Focus | Lessons | Milestones | Roadmap |
|---|---|---|---|---|---|
| 0 Setup | Day 0 | Flute check, tools, habits, safety | L00, L01 | M0 | [phase-0](phases/phase-0-setup.md) |
| 1 Foundations | 5-8 weeks | Posture, breath, tone, `.P`-`G`, pulse, sargam, first melodies | L01-L12 | M1, M2 | [phase-1](phases/phase-1-foundations.md) (day by day) |
| 2 Core technique | 10-14 weeks | Full middle octave, articulation, tala, half-hole Ma, intonation, song method | L13-L18 | M3, M4 | [phase-2](phases/phase-2-core-technique.md) |
| 3 Musicianship | 5-7 months | First ragas, upper octave, ornaments, songs by ear, notation, improvisation/composition basics | L19-L24, L27, L29, L30 | M5, M6, M7 | [phase-3](phases/phase-3-musicianship.md) |
| 4 Intermediate | 8-12 months | 12 notes, more ragas, transposition, alap, bandish/taans/tihai, gamak, accompaniment, style | L25, L26, L28, L31-L36 | M8, M9 | [phase-4](phases/phase-4-intermediate-artistry.md) |
| 5 Advanced | Open-ended | Full presentations, hardest ragas, vilambit, live collaboration, original work, independence | L37 | M10 | [phase-5](phases/phase-5-advanced-independence.md) |

## Teacher checkpoints (Strongly recommended)

A live teacher can see and hear what this text cannot. If you can arrange only a few lessons,
use them here:

| When | What to ask them to check |
|---|---|
| Weeks 2-3 | Embouchure, posture, hand position |
| Around M3 | Overblowing, half-hole Ma, tone |
| Around M5 and M7 | Raga phrasing, upper octave, ornaments |
| Phase 4 onward (monthly if possible) | Alap, taans, gamak, komal intonation |
