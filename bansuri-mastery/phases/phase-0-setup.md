# Phase 0 - Day 0: Setup

[Mastery Map](../00-MASTERY-MAP.md) | Next: [Phase 1](phase-1-foundations.md)

**Time:** one session of 60-90 minutes. Little or no playing yet.
**Goal:** everything is ready, so that from Day 1 every minute goes into learning.
**Objectives:** INS-01..06, BOD-01, BOD-03, BOD-06, BRE-06, PRA-01, PRF-03.

## Checklist

### A. Your flute (30 min) - [L00](../lessons/L00-day-0-your-flute.md)

- [ ] Read L00. Learn the parts of the flute (INS-01).
- [ ] Do the inspection checklist: cracks, bindings, cork, splinters (INS-03).
- [ ] Look for the maker's care instructions (oiling, storage). Write them in your log (INS-05).
- [ ] Decide which side you will hold the flute on. Write it down. **Never switch later.**
- [ ] Set up the care routine: cloth, bag, storage place away from sun and heaters (INS-04).

### B. Tools (20 min)

| Tool | Choice | Notes |
|---|---|---|
| **Bansuri Practice Bench** (tanpura, tala metronome, pitch checker, fingering chart) | [Practice Bench](../tools/index.md) ([open it](../tools/practice-bench.html)) | Covers the drone, tuner and metronome rows below. If its live tuner cannot use your microphone, use its recording check |
| Drone (tanpura) set to **C** | [R-A01](../02-RESOURCE-LIBRARY.md#71-drone-tanpura--shruti-box) browser shruti box, or an app ([R-A02](../02-RESOURCE-LIBRARY.md#71-drone-tanpura--shruti-box)) | Test that you can hear it through a speaker, not only earphones |
| Chromatic tuner | Any app that shows cents ([R-A10](../02-RESOURCE-LIBRARY.md#72-tuner-metronome-recording-slow-down)-R-A12) | Must show note name **and** cents |
| Metronome | Any free app (most tuners include one) | Must be adjustable 40-200 BPM |
| Recorder | Phone voice recorder or [R-A13](../02-RESOURCE-LIBRARY.md#72-tuner-metronome-recording-slow-down) Audacity | Test that playback is clear |
| Practice log | Notebook or a copy of the log template in [L01](../lessons/L01-how-to-practise.md) | Kept next to the flute |
| Mirror | Any mirror at face height | For embouchure and posture |

### C. How you will practise (15 min) - [L01](../lessons/L01-how-to-practise.md)

- [ ] Read L01. Understand the daily session structure and the "3 clean in a row" rule.
- [ ] Choose a fixed daily practice time and place (quiet, chair or floor mat, mirror nearby).
- [ ] Read [03-PROGRESS-TRACKER.md](../03-PROGRESS-TRACKER.md) and [the conventions](../05-CONVENTIONS-AND-NOTATION-KEY.md) (skim; you will learn them gradually).

### D. Safety (5 min)

- [ ] Read the dizziness protocol in [L03](../lessons/L03-breathing-basics.md) (BRE-06).
- [ ] Read the warning signs in [TS-08](../troubleshooting/TS-08-body-pain-and-tension.md) (BOD-08).

### E. Optional, strongly recommended

- [ ] Find a teacher (in person or online) for occasional checks. Book a first check for
      around Week 2-3, when you can make a sound and want your embouchure seen
      ([R-C01](../02-RESOURCE-LIBRARY.md#4-courses-and-teachers-paid-or-structured), [R-C03](../02-RESOURCE-LIBRARY.md#4-courses-and-teachers-paid-or-structured)).
- [ ] Order *How To Play the Bansuri* (Lyon Leifer) ([R-B01](../02-RESOURCE-LIBRARY.md#6-books)),
      written for a C bansuri.

## Exit criterion

Complete [M0 - Setup](../projects/M0-setup.md). Then start Phase 1 tomorrow.
