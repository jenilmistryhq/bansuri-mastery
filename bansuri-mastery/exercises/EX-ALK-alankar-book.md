# EX-ALK: Alankar Book

[Back to Mastery Map](../00-MASTERY-MAP.md) | Lesson: [L12 Alankars](../lessons/L12-alankars.md) | Notation: [Conventions](../05-CONVENTIONS-AND-NOTATION-KEY.md)

**Objectives:** FNG-02, FNG-03, FNG-05, FNG-06, FNG-07, FNG-08, FNG-09, FNG-13, RHY-03, RHY-04, RHY-10, NOT-01

An **alankar** (also called palta) is a fixed note pattern moved step by step up and down a
scale. [L12](../lessons/L12-alankars.md) explains why they matter, how to practise them, and
defines the **10 numbered formulas** used everywhere in this course. This book writes those same
10 formulas out for every scale you unlock later.

## Reading the tables

- Every note gets **one beat**. `|` only separates pattern groups; **do not pause** there.
- Play **aroh, then avroh** (up, then down) as one repetition. Breathe at the turnaround.
- **Formula 1** ends with `- -`: hold the last note 2 extra beats.
- **Formula 7** has repeated notes: separate them with a breath pulse ("hu") or, after
  [L13](../lessons/L13-articulation-tonguing-and-slurs.md), with the tongue. When the scale has
  an odd number of notes, the last group has only 2 notes; hold the last note 2 beats.
- Use a **C drone** and a **metronome**.

### BPM ladder (as in L12)

| Stage | Notes per beat | BPM | When |
|---|---|---|---|
| 1 | 1 | 60, then +4 BPM steps to 80 | Learning a new version |
| 2 | 2 | 60, then +4 to 80 | After 3 clean runs at 80 one-per-beat |
| 3 | 2 | 80 to 100 | Phase 3 |
| 4 | 4 | 60, then +4 to 80+ | Phase 4 (taan preparation, FNG-13) |

**"3 clean in a row" rule:** move up only after three consecutive clean runs (no wrong notes,
squeaks or blips; steady tempo), judged by **recording**, not by feel
([L08](../lessons/L08-recording-and-self-assessment.md)). Fail twice at a new step: drop back one
step for two days.

**Suggested rotation (block C of your session, 10-12 min):** 3 alankars per day from your
newest version plus 1 from an older version for review.

## Version F: raga-specific

These apply the same 10 formulas to raga scales. **Raga rules override the formulas.** In a
real raga some generated groups would be unusual or avoided (for example Yaman rarely uses
`S R` going up from Sa). Treat these as finger and intonation training, and check musical
phrases against the [raga cards](../ragas/README.md).

<summary>Self-check for alankars you invent</summary>

Every alankar keeps **the same shape, moved up one note each time**. Write the first note of
each group in a column. Going up it must read the scale in order; going down, the scale in
reverse. If any group's internal steps differ from the first group's, it is wrong.
